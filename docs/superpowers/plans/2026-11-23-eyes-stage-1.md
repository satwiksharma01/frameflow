# The Agent's Eyes, Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Frameflow's agent eyes. Each clip gets a study at prepare (cuts, a frame sheet, quality, speech regions); the agent writes moments that feed a shot list in the brief and storyboard requests; speech means speech; and a look step judges a frame sheet of every build.

**Architecture:** Two new modules. `project/vad.py` runs Silero VAD through ONNX Runtime. `project/eyes.py` studies clips, draws sheets, checks moments and writes shot lines. `produce.py` calls them at prepare, adds `--shots` and `--look`, and puts the shot list in its requests. `first_cut.py` gains the speech regions, and `app_think.py` gains a describe step for thinkers that can see. The engine still never calls a model: it writes requests and checks answers.

**Tech Stack:** Python 3.13, `unittest`, OpenCV (frames, measures, sheet drawing with its built-in Hershey font), NumPy, ONNX Runtime 1.25 (already installed), ffmpeg (CI installs it).

**Spec:** `docs/superpowers/specs/2026-11-23-eyes-stage-1-design.md`

## Global Constraints

- **Dependencies:** no PyTorch, no new pip dependency. Silero VAD runs through `onnxruntime`.
- **The model:** pinned to commit `bfdc0193023f121ea5b3cc7b176dbed570a68a59`, file `src/silero_vad/data/silero_vad.onnx`, sha256 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`, 2,327,524 bytes. It downloads on first use to `models/silero_vad.onnx`, which is git-ignored with `models/`.
- **The model's call:**
  - inputs: `input` float32 `[1, 576]` (the last 64 samples of the previous call, then 512 new ones, at 16 kHz), `state` float32 `[2, 1, 128]`, `sr` int64 `16000`;
  - outputs: `output` `[1, 1]` (speech probability) and `stateN`.
- **Without the model, the speech behaviour is exactly today's.** CI has no model: its logic is tested with a stand-in, and the one real-model test skips.
- **Values the spec fixes:**
  - scene threshold `0.3`;
  - at most `60` frames per sheet;
  - minimum step `0.5` s;
  - a closer look at `4` frames a second by default;
  - flags: `soft` under 40% of the clip's median sharpness, `dark` under mean luma 40, `blown` over 220;
  - framing: `close`, `medium` or `wide`;
  - the look sheet steps max(0.5 s, length ÷ 40), plus 0, 0.5, 1.0, 1.5 and 2.0 s, plus every scene's first frame;
  - the vertical safe area: the top 14%, the bottom 35%, 6% at each side.
- **The storyboard's schema is unchanged.** The app gets no new screens.
- **Run tests with** `python -m unittest discover -s tests -p "<file>"`. New files use LF; every existing file keeps its own line endings.
- **No commits without Satwik's word.** Each task ends with its files ready; on his word, commit by path with no Co-Authored-By line.

## Review Focus

1. **A clip with no audio track** (a silent screen recording): the study has `speech: []`, nothing crashes. Pinned in Task 2.
2. **A very short clip** (under 0.5 s): one sample, a one-frame sheet. Pinned in Task 2.
3. **A phone clip stored sideways with rotation metadata** (run 11's WA0025): the sheet's frames are upright. Pinned in Task 2.
4. **Try again on the same clips:** neither the study nor the moments are redone. Pinned in Task 5.

**Files:**

**Interfaces:**
- Produces:
  - `MODEL_PATH: Path` (`REPO_ROOT / "models" / "silero_vad.onnx"`), `MODEL_URL`, `MODEL_SHA256`;
  - `class VadError(Exception)`;
  - `installed() -> bool`;
  - `install() -> str`: downloads with `transcribe._download`, returns what it did;
  - `regions(probs: list[float], hop: float = 0.032, threshold: float = 0.5, min_speech: float = 0.25, min_silence: float = 0.1, pad: float = 0.03) -> list[dict]`: pure. Chunk `i` covers `i*hop` to `(i+1)*hop`. Runs at or over the threshold become regions; gaps shorter than `min_silence` merge; regions shorter than `min_speech` drop; each is padded by `pad`, clamped at 0. Returns `{"start", "end"}` rounded to 3 places;
  - `speech(path: Path | str) -> list[dict]`: decodes to 16 kHz mono float32 with ffmpeg (`-ac 1 -ar 16000 -f f32le`), returns `[]` when the file has no audio, runs the model chunk by chunk, and returns `regions(...)`. Raises `VadError` when the model isn't installed;
  - `editor_agent.ensure_speech(transcript)`: when the transcript has `speech`, the measure is the sum of its regions and the message reads `"no usable speech: {s:.1f}s of speech in the {d}s recording. If this clip has no talking, add it as a picture or clip, not as a recording."` Otherwise today's measure and message, unchanged;
  - `first_cut.prepare`: after `transcribe`, when `vad.installed()`, set `transcript["speech"] = vad.speech(source)`. Drop every segment whose span overlaps no region, then print `"    {n} segment(s) over no speech dropped"` when `n > 0`. Write the transcript, then call `ensure_speech`.

    def test_runs_over_the_threshold_become_padded_regions(self):
        probs = [0.0] * 10 + [0.9] * 20 + [0.0] * 10          # 0.32 s to 0.96 s

### Task 2: A clip's study (`project/eyes.py`)

**Files:**
- Create: `project/eyes.py`, `project/schema/study.schema.json`
- Modify: `project/validate.py` (register `study`), `project/produce.py` (`stamp` becomes `from project.eyes import stamp`; its old body moves to `eyes`)
- Test: `tests/test_eyes.py` (class `TestStudy`)

**Interfaces:**
- Consumes: `vad.installed`, `vad.speech` (Task 1).
- Produces:
  - **Constants:** `SCENE_THRESHOLD = 0.3`, `MAX_FRAMES = 60`, `MIN_STEP = 0.5`, `SOFT_SHARE = 0.4`, `DARK = 40`, `BLOWN = 220`, `SHAKY` (motion, the builder's call), `STUDY = "study.json"`, `SHEET = "sheet.jpg"`.
  - `stamp(path: Path) -> dict`: moved unchanged from `produce`.
  - `step_for(duration: float, frames: int = MAX_FRAMES, least: float = MIN_STEP) -> float`: `max(least, duration / frames)`.
  - `cuts(clip: Path) -> list[float]`: ffmpeg `select='gt(scene,0.3)',showinfo`, parsed for `pts_time`.
  - `frames_at(clip: Path, times: list[float]) -> list[np.ndarray]`: read with OpenCV seeking by milliseconds, upright. OpenCV applies display rotation itself; Review Focus 3 checks it.
  - `measures(frames: list[np.ndarray]) -> list[dict]`:
    - `sharp`: the variance of `cv2.Laplacian` on grey;
    - `bright`: mean luma;
    - `motion`: the mean absolute difference from the previous frame, resized to 64 px wide, 0 for the first.
  - `flags(samples: list[dict], start: float, end: float) -> list[str]`: which of `soft`, `dark`, `blown`, `shaky` hold for most samples in `[start, end]`. `soft` is judged against the clip's median sharpness.
  - `draw_sheet(frames: list[np.ndarray], labels: list[str], out: Path, across: int = 10, width: int = 240) -> Path`: tiles keep each frame's aspect, and labels are drawn with `cv2.putText` in a dark box in each tile's corner.
  - `study(clip: Path, out_dir: Path) -> dict`:
    - writes `study.json` and `sheet.jpg`, sampling at `step_for(duration)` from 0;
    - labels read like `"8.0s"`;
    - `speech` comes from `vad.speech` when installed and the clip has audio, otherwise `[]`;
    - returns the study;
    - reuses an existing `study.json` whose `stamp` equals `stamp(clip)` without reading a frame.
  - `main()` subcommands: `study <clip> <out>`, `install` (runs `vad.install`). Task 3 adds `sheet`.

- Produces:
  - `closer(clip: Path, start: float, end: float, out: Path, per_second: float = 4.0) -> Path`: a sheet of frames from `start`, every `1/per_second`, before `end`, labelled to one decimal.

    - without: one line from the study, `- {name}, {duration:.1f} s · {n} cut(s) · speech {speech_seconds:.1f} s · {flags over the whole clip or "sharp"}`.

**Interfaces:**

- Produces:
  - **`prepare` studies every footage video and every asset with `kind == "clip"`** into `eyes/<stem>`, suffixed `-2`, `-3` and so on when a stem repeats. It records the relative folder as each entry's `"eyes"` key in `inputs.json`.
  - **It returns `eyes/shots_request.md` when any clip was studied,** and `brief_request.md` otherwise, as today.
  - **`shots_request(folder: Path, inputs: dict) -> Path`** writes `eyes/shots_request.md`:
    - for each clip with no `moments.json` yet: its name, length, cuts, speech summary, overall flags and sheet path;
    - the command for a closer look;
    - the moment fields with the framing values;
    - "write `eyes/moments.json`, then run `python -m project.produce "<folder>" --shots`".

    Clips already described are listed as done.
  - **`shots(folder: Path) -> Path`:**
    - reads `eyes/moments.json` when present, validates it as `moments`, and checks each clip's list with `moment_problems`;
    - raises `ProduceError` listing every problem, or naming a `clip` that isn't one of the video's;
    - stores each clip's list in its `eyes/<folder>/moments.json`;
    - writes and returns `brief_request.md`.

    A clip without moments is allowed: its shot line comes from its study.
  - **`_inventory(inputs: dict, folder: Path | None = None) -> str`:** a clip entry with `"eyes"` (and a `folder`) is replaced by its `shot_lines`. Everything else is unchanged.
  - **CLI:** `--shots` prints `Next: read <brief_request.md>`. `--prepare` prints `Next: read <path returned>`.
  - **`reference.prepare` writes each footage and asset entry without its `"eyes"` key,** because Agent Video's inventory refuses fields it doesn't know. `test_reference.py` gains a check that an entry carrying `"eyes"` reaches Agent Video's `inputs.json` without it.
