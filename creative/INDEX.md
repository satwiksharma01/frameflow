# Frameflow's creative knowledge

Read this first, then only the file the step in hand needs. Requests point here; they never copy these files.

- `modes.md` — the five modes (stop, show, persuade, teach, tell): what success is for the viewer, how far a world may reach, what the first two seconds must do, and the questions worth asking.
- `calibration.md` — the habits of AI-made video to treat as already spent, the over-used faces, and the test every direction must pass.
- `world-format.md` — how to write a world for a project's catalog: the file format, the six families, what makes a world a working system, and a complete example.
